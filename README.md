# Coffee & Friends

A responsive front-end website for a coffee shop. The project presents the shop, its menu, and simple account-access screens in a warm, coffee-inspired interface.

## Features

- Home page with an introduction and about section
- Menu organised into coffee, juice, and dessert categories
- Product cards with images, descriptions, and prices in EGP
- Login and sign-up forms with browser validation
- Shared navigation, branding, footer, and responsive styling

## Technology

- HTML5
- CSS3
- Google Fonts (Pacifico and Poppins)

## Project Structure

```text
Coffee-Shop/
├── index.html          # Home page
├── htdocs/
│   ├── Menu.html       # Menu page
│   ├── login.html      # Login page
│   └── signup.html     # Sign-up page
├── style/
│   └── style.css       # Shared styles
└── media/              # Logo, product images, and social icons
```

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in a modern web browser.
3. Use the navigation links to explore the menu and account pages.

No build step or package installation is required.

## Notes

This is a static front-end project. The login, sign-up, and order controls provide the interface only; they are not connected to a back-end service or database.
